Buat lisensi baru

Pembeli melihat ID Perangkat di layar aktivasi aplikasi, lalu mengirimnya ke Anda. Lisensi yang diisi ID ini hanya berlaku di HP tersebut, dan langsung masuk otomatis ke HP itu (realtime) bila Firebase sudah diisi.

Kode Grup menghubungkan data satu usaha. Pilih “Lisensi Grup: Smart + Pantau + Supir” untuk memakai SATU kode lisensi di ketiga aplikasi dan semua HP Supir. Kosongkan ID Perangkat. Data tetap mengikuti Kode Grup.

Lisensi siap dikirim

Tombol “Kirim WA + ID Card” membuka menu bagikan HP: pilih WhatsApp lalu kontak pembeli. Pesan berisi kode lisensi dan gambar ID Card.

Cabut Lisensi

Cabut mengunci aplikasi di HP pembeli secara realtime (maks. 30 detik bila online) dan mengembalikannya ke halaman lisensi. Pulihkan membatalkan pencabutan; lalu tekan Kirim ulang di tab Daftar.

Daftar cabut (cadangan)

Cadangan untuk pencabutan tanpa Firebase: simpan sebagai revoked.json di folder aplikasi.

Info aplikasi
Pengaturan ID Card

QR pada ID Card membuka chat WhatsApp developer berisi “Verifikasi lisensi …”. Bila Alamat verifikasi diisi, QR berisi alamat itu ditambah ?kode=KODE.

Panduan singkat

1) Buat lisensi di tab Buat. 2) Tekan “Kirim WA + ID Card” untuk mengirim kode dan kartu ke pembeli. 3) Lihat omzet di tab Sales dan ringkasan di tab Laporan. 4) Cabut di tab Cabut Lisensi bila perlu. 5) Simpan kunci pribadi di tempat aman (tab Kunci).

ID Card
Server realtime (Firebase)

Alamat Realtime Database yang sama dengan yang dipasang di aplikasi Petugas dan Pantau. Dipakai untuk mengirim lisensi dan pencabutan secara realtime.

Kunci tanda tangan

Kunci pribadi hanya tersimpan di browser perangkat ini (per alamat web). Bila membuka Admin dari alamat/HP lain, tempel kunci pribadi di atas lalu Simpan. Jangan bagikan kunci ini ke siapa pun.

Uji kode lisensi

Tempel kode ATK1.… untuk memeriksa apakah kode itu sah di aplikasi Smart/Pantau (tanda tangan, aplikasi tujuan, ID HP, masa berlaku).

Kunci publik (dipasang di aplikasi)

Baris ini harus sama dengan LICENSE_PUBKEY di file aplikasi. Jika berbeda, lisensi yang dibuat tidak akan diterima.

Daftar hanya tersimpan di perangkat ini. Salin cadangannya secara berkala.
